# Bank Customer Segmentation

## Project Overview
This project explores customer behaviour in the banking sector to uncover patterns associated with churn. By applying data science techniques—particularly clustering using KMeans—this analysis aims to identify distinct customer segments based on financial and behavioural attributes. The project also evaluates how these segments correlate with churn risk, providing insights that can support retention, product targeting, and personalised customer strategies.

## Folder Structure

- **Data/**
  - `Bank_Churn.csv`: Main data source.
- **Notebooks/**
  - `Bank Customer Segmentation.ipynb`: Main notebook file with the analysis.
  
## How to Run the Analysis
Load the `Bank Customer Segmentation.ipynb` notebook file using Jupyter notebook (or similar software).
